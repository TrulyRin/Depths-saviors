# Theme

## Compact token summary

- Font: Inter, system UI fallback.
- Base style: dark glass panels with teal primary accents, rounded 8–16px controls, responsive fixed sidebar.
- Main tokens are defined in `style.css` and consumed by dashboard CSS: `--bg-surface`, `--border-light`, `--primary`, `--primary-glow`, `--text-main`, `--text-muted`, `--radius`, and `--nav-height`.
- Dashboard uses Discord blurple for sign-in and teal for normal save actions.

## Source files

- `style.css` contains global tokens and navigation styling.
- `dashboard.css` contains dashboard shell, forms, cards, tables, toggles, and responsive breakpoints.
