# Shared components

This static-site dashboard has no framework component directory. Reusable UI is implemented as CSS classes and the `DS` controller in `dashboard.js`.

## Dashboard controller

- Source: `dashboard.js`
- Description: session, server selector, navigation, panels, and authenticated API calls.
- Reusable UI patterns: `setting-card`, `setting-row`, `toggle`, `ds-select`, `ds-input`, `btn-save`, `ds-badge`.
